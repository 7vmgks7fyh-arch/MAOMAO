# Antigravity 星辰猫猫桌宠 v3.0

![星辰猫猫桌宠动作预览](assets/sprites_preview.png)

基于 `Python + PySide6` 制作的 Windows 透明无边框置顶桌宠，具备 **10 套定制全身 Q 版星辰猫猫动作立绘**、二阶弹簧阻尼物理、连贯动作编排引擎与像素级透明点击穿透。

## 启动方式

- **首次下载/克隆使用**：直接双击 `一键安装并启动.bat`（自动创建 `.venv`、安装 `PySide6` 依赖并静默启动桌宠）
- **后续无黑框启动**：直接双击 `启动星辰猫猫桌宠.vbs`（自带单实例防多开保护，重复启动会唤醒已有猫猫）
- **终端调试启动**：双击 `start_pet.bat`，或在终端运行：
  ```powershell
  .\.venv\Scripts\python.exe main.py
  ```

## v3.0 核心特性与玩法

### 1. 10 套全身动作与连贯动作链
- **10 套专属透明精灵**：待机 (`idle`)、开心蹦跳 (`happy`)、四拍走路左/右步态 (`walk_a` / `walk_b`)、乖巧跪坐 (`sit`)、大口啃小鱼干 (`eat`)、害羞蹭手 (`shy`)、趴地打盹 (`sleep`)、委屈被拎起 (`dragged`)、大脑过载 (`overload`)。
- **二阶弹簧物理 + 3D 丝滑转身**：通过 `motion.py` 的 `PoseRig` 统一驱动 6 通道物理弹簧，消除状态切换生硬感，左右转身带平滑水平压缩翻转；状态交替具备 0.14s 交叉淡入淡出。
- **6 条起承转合连贯动作链**：
  - **入睡 & 苏醒链**：`idle → sit`（揉眼坐下）→ `sleep`（趴地冒 `Zzz`）→ `sit`（睡醒坐起）→ `happy`（伸懒腰）→ `idle`
  - **吃鱼咀嚼链**：抛物线小鱼干飞入怀中 → `eat`（捧鱼咀嚼弹性脉冲）→ `happy`（吃饱欢呼）→ `idle`
  - **顺毛蹭手链**：轻抚头顶/脸颊 → `shy`（朝光标微歪头贴贴 + 爱心）→ `happy` → `idle`
  - **反重力 360° 后空翻炫技链**：`sit`（下压蓄力）→ 腾空 360° 后空翻（螺旋星尘）→ `happy`（完美落地 Pose）→ `idle`
  - **过载恢复链**：`overload`（抱头抖动）→ `sit`（瘫坐缓神）→ `idle`
  - **四拍真实步态**：`walk_a → idle → walk_b → idle` 交替迈步

### 2. 深度互动玩法
- **🪄 逗猫星光棒模式**：开启后鼠标化身可穿透的旋转星光点，猫猫加速奔跑/飞扑追逐，近距离进入「俯身蓄力 (`sit`) → 纵身飞扑」抓捕星光点，抓中炸出星芒烟花与好感度（按 `Esc` 或右键一键收起）。
- **🐟 小鱼干大餐 & 中键快捷投喂**：支持**鼠标中键**随时丢出一条小鱼干，或右键触发连抛 3 条的小鱼干大餐；新增「🍙 饱食活力」养成进度条。
- **📏 鼠标滚轮无级缩放**：在猫猫身上滚动滚轮即可在 `120px～260px` 之间丝滑调整体型大小并自动记忆。
- **👀 近距离注视 & 分区点击 & 悬停 rua 头**：靠近猫猫时会温柔歪头看你；头顶轻划会害羞蹭手；点击头顶、脸颊、脚底各有不同反馈；连点 4 次触发大脑过载。
- **像素级点击穿透 & 桌面小助手**：透明留白处全穿透不遮挡窗口/图标；集成 **🍅 25分钟番茄专注钟**、**💧 45分钟喝水提醒**、7 种轻柔合成音效、**🚀 开机自启**与本地状态持久化 (`data/state.json`)。

## 项目结构

- [main.py](main.py)：桌宠主程序（10 套精灵、动作链编排、像素穿透、逗猫棒追捕、飞鱼与粒子绘制）
- [motion.py](motion.py)：二阶弹簧物理引擎（`SpringValue`、`PoseRig`）与动作编排队列（`ActionQueue`）
- [widgets.py](widgets.py)：渐变星辰台词气泡、`LaserToyWidget` 逗猫星光棒光球与 `StatusDialog` 状态卡片
- [config_store.py](config_store.py)：本地 JSON 状态持久化（含饱食度、炫技数、无级体型）与 Windows 注册表开机自启
- [sound_fx.py](sound_fx.py)：标准库 WAV 柔美音效合成（7 种音效含 `eat` / `shy`）与播放管理
- [scripts/prepare_sprites.py](scripts/prepare_sprites.py)：10 张原始立绘精准抠图与抗锯齿处理脚本
